# Installation & setup

From package installation to your first styled, accessible interface.

## Requirements

Use React and React DOM 18 or 19, matching the package peer dependencies. TypeScript is recommended for typed fields, table rows and component props. Your application bundler must process CSS imports.

| Import | Purpose |
| --- | --- |
| @blencm/ui | Public components, hooks, types and style helpers. ESM and CommonJS entries are provided. |
| @blencm/ui/style.css | Explicit access to the compiled stylesheet. |
| @blencm/ui/dist/style.css | Compatibility alias for the same stylesheet. |

## Install the package

Choose one package manager. React and React DOM must also be installed in your application.


```bash
pnpm add @blencm/ui
# npm install @blencm/ui
# yarn add @blencm/ui
```

## Render your first component

The package entry loads its compiled CSS, theme tokens and base reset as side effects. You do not need to copy component source files into your application.


```tsx
import { Button, Card, CardContent, CardHeader, CardTitle } from '@blencm/ui';

export function Welcome() {
  return (
    <Card>
      <CardHeader><CardTitle>Project workspace</CardTitle></CardHeader>
      <CardContent>
        <Button onClick={() => window.alert('Ready')}>Get started</Button>
      </CardContent>
    </Card>
  );
}
```

## Styles and application CSS

If your bundler does not retain CSS side effects, explicitly import the stylesheet in your application entry or global layout. Load your theme overrides after the library stylesheet.

The compiled stylesheet includes a base reset and body theme styles; review these when integrating with an existing design system. Tailwind is needed only if your application wants to generate additional utilities. Custom utility classes must be generated by your application; avoid dynamically constructing class names.


```tsx
import '@blencm/ui/style.css';
import './app.css';
```

## Framework integration

In Vite, import the library from your React components and put optional global CSS imports in your application entry. In a Next.js App Router application, put stateful controls and providers behind an application client boundary; import global styles from the root layout.

CSS imports are part of the distributed JavaScript entry, including CommonJS. A bare Node.js require without a CSS-aware loader is not an application rendering environment. Validate server rendering with your framework and the components you use.


```tsx
'use client';

import { useState } from 'react';
import { Button } from '@blencm/ui';

export default function Counter() {
  const [count, setCount] = useState(0);
  return <Button onClick={() => setCount(count + 1)}>Count: {count}</Button>;
}
```

## Install only the providers you use

Basic controls need no global provider. Tooltip needs TooltipProvider. Form provides React Hook Form context. The two toast systems have separate renderers. next-themes is useful when your app switches between light and dark themes.


```tsx
import type { ReactNode } from 'react';
import { TooltipProvider, Toaster } from '@blencm/ui';

export function Providers({ children }: { children: ReactNode }) {
  return (
    <TooltipProvider>
      {children}
      <Toaster />
    </TooltipProvider>
  );
}
```

## Optional editor setup

The bundled CLI merges Tailwind IntelliSense settings and recommends the Tailwind CSS extension in .vscode. It does not install or copy components. Run it from your application directory.


```bash
pnpm exec blencm-ui init-vscode
# npx blencm-ui init-vscode
```
